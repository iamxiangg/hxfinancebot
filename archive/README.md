# Archived Scripts

These scripts are preserved here as legacy one-file entry points from the
pre-modular repo layout.

They are still runnable, and some GitHub Actions workflows still invoke them
from this folder, but they are no longer the preferred place for new work.

Current rule of thumb:

- new long-term stock pipeline work belongs in `funnel/`
- new scanner engines belong in `scanners/`
- new tactical alert runners belong in `tactical/`
- archived one-file scripts stay here until they are either replaced or retired
